# GDXT Website

React (Vite) implementation of the GDXT marketing site, built from the Figma design.

## Pages
- Home
- About
- Services
- Training
- Contact

## Stack
- React 19 + Vite
- react-router-dom for client-side routing
- Plain CSS with design tokens (no CSS framework dependency)

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Notes
- The homepage is fully responsive (desktop and mobile), matching the responsive behavior of the other pages in the Figma file.
- The GDXT logo is a shared `Logo` component used in the navbar and footer.
